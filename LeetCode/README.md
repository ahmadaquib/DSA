```

│
├── README.md
│
├── 0001-two-sum/
│   ├── Question.md
│   ├── Approach.md
│   ├── Answer.cpp
│   └── Answer.py        (optional — only if also solved in Python)
│
├── 0015-3sum/
│   ├── Question.md
│   ├── Approach.md
│   └── Answer.cpp
│
└── ...
```

### Naming convention

`<4-digit LeetCode number>-<problem-slug>/` — e.g. `0001-two-sum`, `0049-group-anagrams`.

Zero-padding keeps folders sorted in number order in any file explorer or `ls`, regardless of how many digits the problem number has.

---

## 📄 File Contents

**`Question.md`**
The problem statement — constraints, examples, difficulty badge, and the original LeetCode link. Kept short; not a copy-paste of the full page.

**`Approach.md`**
The actual thinking: brute force → optimization path, why the final approach works, time/space complexity, and any pattern this reuses from a prior problem.

**`Answer.cpp`**
The working C++ solution (primary language for this repo).

**`Answer.py`** *(optional)*
Included only when the problem is also solved in Python — not required for every problem.
