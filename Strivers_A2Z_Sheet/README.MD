## About

Topic-wise solutions following the sheet's own ordering — manual/from-scratch first pass on each problem before optimizing.

> **Note:** Running any file in this folder requires the repo-root `.vscode/` config and this folder's `input.txt` / `output.txt` (gitignored local scratch files; expected input format is noted at the top of each `.cpp`). See the root `DSA/README.md` for setup.
